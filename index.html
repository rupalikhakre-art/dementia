IDEA TITLE

Proposed Solution: Smriti Setu ("The Memory Bridge")

The Concept

An AI-powered, culturally localized cognitive maintenance platform for elderly dementia patients in the NER.

It utilizes regional motifs and native voice guidance for fully offline digital therapy.

Addressing the Problem

Standard apps rely on confusing Western concepts. Smriti Setu uses familiar, low-stress games to stimulate memory.

It passively tracks reaction times, generating early warnings without forcing clinical tests.

Innovation

  • No "Wrong" Answers: Adaptive games eliminate anxiety triggers.
  • 100% Offline: Local storage (IndexedDB) with deferred syncing.
  • Native Voice: Local language synthesis without cloud APIs.

FEASIBILITY AND VIABILITY

Analysis of Feasibility

Optimized for low-cost Android tablets (1GB RAM). Running purely on native browser APIs eliminates recurring cloud costs, ensuring high economic sustainability for rural healthcare deployments.

Challenges / Risks Strategies for Mitigation
Erratic Connectivity: Poor network in hilly terrains. Offline Engine batches data locally, syncing only when a connection is caught.
Low Tech-Literacy: Poor smartphone navigation skills. Single-tap cards and local voice guidance replace complex menus.
Differentiating Decline: Separating bad days from decay. "Sundowning Alerts" cross-reference daily latency trends to flag anomalies.
