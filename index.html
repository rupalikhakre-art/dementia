IDEA TITLE

Proposed Solution: Smriti Setu ("The Memory Bridge")

The Concept

An AI-powered, culturally localized cognitive maintenance platform for elderly dementia patients in the North Eastern Region (NER).

It replaces foreign interfaces with regional motifs (Assam tea gardens, Muga silk) and native language voice guidance, acting as a digital therapeutic tool that works fully offline.

How it addresses the problem

The Dementia Problem: Standard cognitive apps use Western icons that cause confusion and anxiety in NER elders.

Memory Games & Tracking: By playing familiar, low-stress games, patients stimulate their memory. Behind the scenes, the app passively tracks reaction times, giving caregivers early warnings without forced medical tests.

Innovation & Uniqueness

  • No "Wrong" Answers: Games adapt automatically. Instead of harsh buzzers, the correct answer glows gently to prevent patient anxiety.
  • Works Completely Offline: Runs on local storage (IndexedDB). ASHA workers can sync data later.
  • Built-in Voice Assistance: Talks to the elder in their local language—no internet required.

TECHNICAL APPROACH

Technologies to be used

  • Frontend: React / Vite + TypeScript.
  • Styling: Tailwind CSS (high-contrast ivory palettes).
  • Voice/Audio: Native Web Audio API & Speech Synthesis API.
  • Local Data: HTML5 LocalStorage / IndexedDB.

Methodology & Process Flow

1. UI: Elder plays localized games via High-Contrast Launcher.

2. Telemetry: System tracks micro-latencies & hesitations.

3. Storage: Logged locally in IndexedDB (offline continuity).

4. Sync: Encrypted records batch-sync to clinic upon network detection.

FEASIBILITY AND VIABILITY

Analysis of Feasibility

Smriti Setu is highly viable for rural deployment. It is optimized for low-cost, subsidized Android tablets requiring only a minimum of 1GB RAM. The reliance on native browser APIs (Web Speech/Audio) eliminates recurring external API costs and server dependency, ensuring the project is economically sustainable for rural healthcare initiatives.

Potential Challenges / Risks Strategies for Overcoming Challenges
Erratic 2G/cellular connectivity in hilly terrains. Offline Synchronization Engine batches data locally via IndexedDB, syncing only when a connection is caught.
Low tech-literacy among elderly demographics. Single-tap routine check-cards and voice guidance replace complex smartphone menus.
Differentiating normal bad days from rapid decline. "Sundowning Alerts" cross-reference daily latency trends between specific hours to flag clinical anomalies.

IMPACT AND BENEFITS

For the Elderly Patient

Impact: Reduces cognitive distress and cultural alienation.

Benefits: Provides a zero-frustration interface with sensory-soothing audio that stimulates neuroplasticity. Promotes dignity by using familiar regional contexts.

For the Family Caregiver

Impact: Mitigates caregiver burnout and emotional strain.

Benefits: Automated daily orientation routines and hydration tracking remove daily friction. Passive monitoring provides objective stability indexes for peace of mind.

For Public Health (ASHA / PHC)

Impact: Bridges the specialized neurological care gap in the NER.

Benefits: Enables community-level geriatric tracking under the Ayushman Bharat Digital Mission (ABDM) and generates longitudinal data without requiring specialized geriatricians on-site.
